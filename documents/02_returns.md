# DemoShop returns policy
Fictional training policy, version 2026-10-26. Applies only to the DemoShop example.

## Return eligibility and window
Clothing and footwear may be returned within 14 calendar days after delivery. They must be unused, unwashed, with original tags and packaging. Start a return from My Orders and select the item and reason. A purchase receipt or order number is required.

## Exclusions
Gift cards, personalized products, and opened hygiene products are not eligible for change-of-mind returns. A damaged or incorrect item must instead be handled under the damaged-items policy, including excluded categories.

## Return pickup fees
The first change-of-mind return pickup for an order is free. Each additional change-of-mind pickup for the same order costs INR 99, deducted from the refund. Returns caused by a damaged or incorrect item have no pickup fee.
